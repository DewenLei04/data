# `output/negotiation_memo.pdf`

A searchable PDF memorandum with these sections in order:

1. Executive recommendation
2. Ranked requests
3. Fallback positions
4. Quantified effects
5. Conditions and required consents
6. Explicit concessions
7. Evidence appendix

Each ranked request must identify its source clause, proposed position, fallback position, priority rank, quantified currency effect at the stated scenario, quantified return-rate effect, and supporting files and sections. Currency display uses two decimal places and return-rate display uses four decimal places.

The input corpus defines which requests, conditions, and measurement conventions apply. The PDF must contain selectable text and stable page numbers.
