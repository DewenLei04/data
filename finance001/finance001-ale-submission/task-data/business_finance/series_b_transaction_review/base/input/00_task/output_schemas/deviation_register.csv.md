# `output/deviation_register.csv`

UTF-8 CSV with this exact column order:

1. `term_id`
2. `term_sheet_value`
3. `market_benchmark`
4. `fund_policy_limit`
5. `direction`
6. `severity`
7. `usd_impact`
8. `evidence_file`
9. `evidence_section`
10. `notes`

One row represents one reviewed term. Use the severity vocabulary and applicability rules defined in the governing policy. Currency display uses two decimal places. Do not manufacture rows for values that are not applicable.
