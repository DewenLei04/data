# finance001 ALE-native submission

This directory is the source template for the ALE-native operator package generated by:

```bash
python tools/build_ale_delivery.py
```

The generated package has three distinct installation targets:

1. Copy `tasks/business_finance/series_b_transaction_review/` into the ALE repository's
   matching `tasks/` path.
2. Publish or bake `task-data/business_finance/series_b_transaction_review/base/` through
   the selected `task_data_source`. Input and software are staged before the agent;
   reference must be staged only after the agent exits.
3. Apply `environment-patch/`, build from the official `ale-ubuntu22` image, and register
   the resulting provider image and logical snapshot as `finance001-ubuntu22`.

The environment patch is additive. It must not replace the official CUA server,
`/opt/ale-run/.venv`, Node runtime, desktop startup, or image path conventions.

## Verify the generated package

```bash
python tools/build_ale_delivery.py --verify delivery/finance001-ale-submission
python tools/build_ale_delivery.py --verify-zip delivery/finance001-ale-submission.zip
```

## Verify after installing into an ALE checkout

```bash
uv run python -m ale_run list
uv run python -m ale_run run my_exp.yaml \
  --task business_finance/series_b_transaction_review --dry-run
uv run python -m ale_run run my_exp.yaml \
  --task business_finance/series_b_transaction_review
```

The final command requires an operator-created snapshot and provider credentials. Those
external operations are intentionally not emulated by the local package builder.
